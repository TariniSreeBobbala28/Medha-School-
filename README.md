# Medha International School - Web Portal 🏫

A comprehensive, multi-frame school management and information portal built with a focus on user experience and structured data presentation. This project showcases a school's digital identity, including student registration, academic details, and campus life.

## 🚀 Key Features

* **Multi-Frame Architecture:** Uses a complex `<frameset>` layout to provide a seamless navigation experience (Header, Sidebar, Main Content, and Interaction zones).
* **Dynamic Registration Form:** A functional **PHP-based** admission form that processes student data and generates an instant digital receipt.
* **Interactive Academic Section:** A JavaScript-powered "School Classes" sidebar with toggleable dropdowns for curriculum and teacher details.
* **Multimedia Integration:** Includes a promotional video player and a CSS-animated continuous image scroller for the school gallery.
* **Modern Styling:** Features advanced CSS3 gradients, "bulge" hover effects in the Hall of Fame, and responsive flexbox layouts.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Gradients, Keyframe Animations, Flexbox), JavaScript (DOM Manipulation).
* **Backend:** PHP (Form handling and server-side data processing).
* **Icons:** Font Awesome integration for professional UI elements.

## 📁 Project Structure

* `school_frameset.html`: The core file that stitches the entire layout together.
* `top_header.html`: Branding, logos, and mission marquees.
* `left_frame.html`: Interactive class and subject details.
* `main_frame.html`: Principal's message, Notice Board, and Hall of Fame.
* `form.php`: The admission engine and receipt generator.
* `rgt_bottom_scroll.html`: Automated image gallery.

## ⚙️ How to Run

1.  **Clone the Repo:**
    ```bash
    git clone [https://github.com/YOUR_USERNAME/medha-project.git](https://github.com/YOUR_USERNAME/medha-project.git)
    ```
2.  **Server Setup:** Since the registration form uses **PHP**, you need to run this on a local server like **XAMPP** or **WAMP**.
3.  **Launch:** Move the folder to your `htdocs` directory and open `school_frameset.html` in your browser.
